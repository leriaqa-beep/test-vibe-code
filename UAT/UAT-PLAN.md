# UAT-PLAN — Почему-Ка!

> Версия: 1.0 | Дата: 25 марта 2026

---

## 1. ЦЕЛЬ ТЕСТИРОВАНИЯ

Убедиться, что приложение **Почему-Ка!** соответствует требованиям целевой аудитории и готово к использованию родителями и детьми. UAT проверяет бизнес-сценарии с точки зрения конечного пользователя, а не техническую корректность кода.

---

## 2. ОБЛАСТЬ ТЕСТИРОВАНИЯ

### Включено в UAT

| Модуль | Приоритет |
|--------|----------|
| Аутентификация (регистрация, вход, выход) | Критический |
| Управление профилями детей (создание, редактирование, удаление) | Критический |
| Генерация сказок (текст, вопрос, голосовой ввод) | Критический |
| Просмотр сказки (ридер, рейтинг, сохранение) | Высокий |
| Библиотека сказок (поиск, фильтр, сортировка) | Высокий |
| Создание PDF-книги (выбор историй, скачивание) | Высокий |
| Шаринг (поделиться ссылкой) | Средний |
| Настройки аккаунта (тариф, удаление) | Средний |
| Freemium-лимит и страница подписки | Средний |
| PWA (установка на устройство) | Низкий |
| Mobile UX (safe area, touch targets, навигация) | Высокий |
| Open Graph превью ссылок | Низкий |

### Исключено из UAT

- Оплата подписки (не реализована — demo-режим)
- Административная панель (внутренний инструмент)
- Сброс пароля через email (зависит от внешнего SMTP)

## 6. КРИТЕРИИ ПРИЁМКИ

### Приложение принимается, если:
- Все сценарии **Критического** приоритета: статус PASS
- Все сценарии **Высокого** приоритета: статус PASS или PASS WITH MINOR ISSUES
- Нет незакрытых дефектов уровня **Blocker** или **Critical**
- Мобильный UX: навигация не перекрывает контент, все кнопки нажимаемы

### Приложение НЕ принимается, если:
- Любой сценарий критического приоритета: статус FAIL
- Генерация сказки не работает более 2 из 3 попыток
- Сказка не сохраняется в библиотеке
- PDF не скачивается

---

## 7. КЛАССИФИКАЦИЯ ДЕФЕКТОВ

| Уровень | Описание | Пример |
|---------|---------|-------|
| **Blocker** | Приложение не запускается / ключевой flow недоступен | Белый экран, невозможно войти |
| **Critical** | Основная функция не работает | Сказка не генерируется, PDF не создаётся |
| **Major** | Функция работает с ошибками | Рейтинг не сохраняется, фильтр не сбрасывается |
| **Minor** | Визуальные дефекты, UX-неудобства | Текст обрезан, кнопка расположена неудобно |
| **Trivial** | Незначительные несоответствия | Опечатка, лишний пробел |

## 8. ПРОЦЕСС ФИКСАЦИИ ДЕФЕКТА

При обнаружении дефекта зафиксировать в [UAT-REPORT-TEMPLATE.md](UAT-REPORT-TEMPLATE.md):

1. **ID** дефекта (BUG-001, BUG-002, ...)
2. **Сценарий**, в котором обнаружен
3. **Шаги воспроизведения**
4. **Ожидаемый результат**
5. **Фактический результат**
6. **Скриншот / запись экрана** (если возможно)
7. **Уровень** дефекта
8. **Устройство / браузер**

## 9. ГРАФИК ТЕСТИРОВАНИЯ

| Этап | Действие |
|------|---------|

## 10. УСЛОВИЯ ОСТАНОВКИ ТЕСТИРОВАНИЯ

Тестирование прекращается досрочно, если:
- Обнаружен дефект уровня **Blocker** — до исправления
- Среда тестирования (Render) недоступна более 30 минут
