# UAT — Почему-Ка!

Папка содержит документацию для пользовательского приёмочного тестирования (User Acceptance Testing).

## Состав

| Файл | Описание |
|------|---------|
| [UAT-PLAN.md](UAT-PLAN.md) | Общий план тестирования: цели, окружение, роли, критерии приёмки |
| [UAT-SCENARIOS.md](UAT-SCENARIOS.md) | Все тест-сценарии по модулям с шагами и ожидаемыми результатами |
| [UAT-CHECKLIST.md](UAT-CHECKLIST.md) | Быстрый чеклист для smoke-тестирования перед релизом |
| [UAT-REPORT-TEMPLATE.md](UAT-REPORT-TEMPLATE.md) | Шаблон отчёта по результатам UAT-сессии |

## Среда тестирования

- **Production:** https://pochemu4ki-app.onrender.com
- **Backend API:** https://pochemu4ki-api.onrender.com
